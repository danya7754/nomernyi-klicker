# Номерний клікер 🇺🇦

Мобільна гра-клікер: тисни на український номерний знак і лови рідкісні комбінації.

## Як грати
- **Тисни прямо на номер** у центрі екрана — кожен клік показує новий номер. Гроші за клік не дають.
- Коли випадає рідкісна комбінація, номер **світиться**, а нижче рядок за рядком друкується, **за що** гроші:
  рідкість цифр, рідкість літер, шанс усієї комбінації (наприклад, «1 з 14 443») і бонус рідкості.
  Сума зверху росте разом із поясненням.
- Від **Епічного** і вище фон темніє, з'являється космос, а номер повільно пливе, ніби в невагомості.
- **Зліва вгорі** — твій рахунок і дохід за секунду.
- **Справа вгорі** — аватарка: натисни, щоб вписати ім'я, прізвище, вік і поставити фото.
- **Справа внизу** — скриня з колекцією. Епічні, легендарні й міфічні номери (від «1 з 1 000») потрапляють туди самі,
  їх можна зберігати або **продати** за повну ціну.
- **Зліва внизу** — покращення «Удача»: кожен клік перебирає більше номерів.
- **Внизу посередині** — «Досягнення» (18 нагород з грошовими призами) і «Подарунок»:
  щоденний приз, що росте 7 днів поспіль (500 → 25 000 ₴). Пропустиш день — серія почнеться спочатку.

### Особливі номери
| Тип | Шанс | Як виглядає |
|---|---|---|
| Золотий | 1 з 200 | золотий знак |
| Діамантовий | 1 з 3 000 | знак переливається |
| Іменний | 1 з 5 000 | напис замість цифр: «КОСМОС», «РАКЕТА», «ХАРКІВ»… |

Золото й діамант множать рідкість будь-якого номера: золотий дзеркальний номер — це 1 з 111 × 200 = 1 з 22 200.

### Рідкість
| Рівень | Колір | Шанс | Ціна |
|---|---|---|---|
| Цікавий | блакитний | від 1 з 10 | без нагороди |
| Рідкісний | зелений | від 1 з 100 | ≈ шанс, гроші одразу, у скриню не йде |
| Епічний | фіолетовий | від 1 з 1 000 | ×2 |
| Легендарний | золотий | від 1 з 30 000 | ×5 |
| Міфічний | червоний | від 1 з 500 000 | ×20 |

Цифри: 0007, 1111, 0001, 5000, 1234, 1221, 1212, 1122, 1112, 3400, 0042…
Літери: дзеркальні (АВ…ВА), серія = регіон (АІ…АІ), однакові (…КК), «золотий» регіон (АА, ВВ, НН, КК).
Шанс кожного правила рахується точно, перебором усіх можливих номерів.

## Як запустити на телефоні
Це звичайна веб-сторінка без збірки: `index.html`, `style.css`, `game.js`.
1. У репозиторії GitHub: **Settings → Pages → Deploy from a branch**, обери гілку й папку `/ (root)`.
2. Відкрий посилання на телефоні й натисни «Додати на головний екран» — гра відкриватиметься як застосунок.

Прогрес зберігається в самому браузері телефона.

## Робота без інтернету
- Шрифт номерів лежить у грі (`fonts/`, ліцензія SIL OFL 1.1).
- На сайті (GitHub Pages) працює сервіс-воркер `sw.js`: після першого відкриття гра запускається навіть у режимі польоту.
  Якщо змінюєш файли гри, збільш `VERSION` у `sw.js`.

## Застосунок для iPhone та Android (Capacitor)
Гра загорнута в [Capacitor](https://capacitorjs.com): проєкти лежать у папках `ios/` та `android/`.

| Команда | Що робить |
|---|---|
| `npm install` | встановлює Capacitor |
| `npm run build` | збирає файли гри в `www/` |
| `npm run sync` | збирає гру й копіює її в `ios/` та `android/` |
| `npm run ios` | відкриває проєкт у Xcode (потрібен Mac) |
| `npm run android` | відкриває проєкт в Android Studio |
| `npm run assets` | перемальовує іконки й заставку з папки `assets/` |

**Автоматична збірка.** Після кожної зміни в `main` GitHub Actions збирає Android APK для тестів
(вкладка **Actions** → «Збірка застосунків» → файл `nomernyi-klicker-android`) і перевіряє, що iOS-проєкт компілюється.

### Як викласти в App Store
1. Акаунт **Apple Developer Program** (99 $ на рік; з 18 років — або на когось із батьків).
2. Mac з **Xcode**: `npm install`, потім `npm run ios`.
3. У Xcode: **App → Signing & Capabilities** → вибрати свою команду (Team).
   За потреби змінити ідентифікатор `com.danya7754.nomernyiklicker` у `capacitor.config.json` і в Xcode.
4. **Product → Archive** → **Distribute App** → App Store Connect.
5. На appstoreconnect.apple.com: опис, скриншоти, вікова категорія, політика конфіденційності → надіслати на перевірку.

### Як викласти в Google Play
1. Акаунт **Google Play Console** (25 $ один раз).
2. В Android Studio: **Build → Generate Signed App Bundle** → файл `.aab`.
3. Завантажити `.aab` у Play Console, заповнити опис і скриншоти → надіслати на перевірку.
